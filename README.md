# ClassCommander — Downloads / Завантаження

ClassCommander provides teacher-controlled classroom management and testing.
This repository distributes official installers and update packages. Application
source code is maintained separately.

ClassCommander — програма керування комп’ютерним класом і тестування під контролем
учителя. Цей репозиторій містить офіційні інсталятори та пакети оновлення.
Вихідний код програми зберігається окремо.

## Download / Завантажити

Open [Releases](https://github.com/TarasMotuschuk/ClassCommander-Releases/releases)
and select a published version. / Відкрийте розділ Releases і виберіть версію.

- `ClassCommander.Setup.msi`: Windows installer / інсталятор Windows.
- `ClassCommander.Setup.pkg`: macOS Apple Silicon installer / інсталятор macOS Apple Silicon.
- `student-agent-update-<version>.zip`: Windows student-agent update bundle / пакет оновлення учнівського агента Windows.
- `student-agent-update-<version>.sha256.txt`: ZIP checksum / контрольна сума ZIP.
- `student-agent-version.json`: student-agent update manifest / маніфест оновлення агента.
- `classcommander-client-version.json`: teacher installer URLs and checksums / адреси та контрольні суми інсталяторів учителя.

GitHub's automatic **Source code** archives contain only this distribution
repository's documentation. Choose the MSI/PKG files to install the application.
Автоматичні архіви Source code містять лише документацію цього репозиторію.
Для встановлення вибирайте MSI/PKG.

Release assets will appear after the publication pipeline completes.
Файли релізу з’являться після завершення процесу публікації.
